installed mods and back up the test save. Uninstall by restoring that backup
and reapplying desired mods; restore the save backup to undo saved ordering.

PC controls while the lower power-selection bar is open:
- Space alternates the two pages, with the existing power-icon fade.
- Click an occupied power to use it. Empty slots do not activate or show names.
- Hold left mouse and drag to move to a hole or swap with an occupied slot.
- While dragging Shepard's power, press Space, wait for the fade, then release
  on the other page. The captured power stays attached to the cursor.
- Each companion's powers can move only within that companion's five slots.
  PC drops apply that companion's persistent layout using physical slots.
- Release outside a valid destination to cancel. Closing or losing focus
  cancels; releasing during the page fade also cancels.
- Dragging onto a native upper quickslot keeps vanilla assignment behavior.
  Existing upper-quickslot drags and weapon selection retain their native path.

PC and controller reuse the same save layout. Opening always starts on page 0.
The shared combo outlines, availability refresh, normal NotSuggested artwork,
empty-slot handling and contextual green destination borders run in PC mode.
Keyboard assignment labels read the eight existing quickslots; they do not
create new bindings. HUD proportions and input settings are not adjusted.
