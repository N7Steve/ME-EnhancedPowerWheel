CONTROLS
R3 toggles between page 0 and page 1 (eight player positions each).
LB on a player power picks it up. R3 can switch page while it is selected.
LB on an empty player position moves the picked power there.
LB on an occupied player position swaps the two powers.
LB on the same position cancels the pick.
A activates the hovered occupied power on either page; empty slots cannot activate.
Squad powers stay on page 0. They are not included in ordering.
X/B retain native mapping actions on occupied page 0.
Pagination does not rewrite controller assignments or PC quickslots.

PERSISTENCE LIMIT
Ordering survives wheel close/reopen in the same GUI/game session only.
It is not written into saves. Destroying the Flash panel discards it.
Session changes that reuse the same panel have not been tested.
A change in native source power order resets the layout to avoid stale source indices.
This POC relocates the original eight native player entries into sixteen positions;
it does not collect additional powers beyond the native source limit.
