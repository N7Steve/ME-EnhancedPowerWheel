CONTROLS
R3 toggles between page 0 and page 1 (eight player positions each).
LB on a player power picks it up. R3 can switch page while it is selected.
LB on an empty player position moves the picked power there.
LB on an occupied player position swaps the two powers.
LB on the same position cancels the pick.
A activates the hovered occupied power on either page; empty slots cannot activate.
Squad powers stay on page 0. They are not included in ordering.
X/B retain native mapping actions on occupied page 0.
Pagination does not rewrite controller assignments or PC quickslots.

NOTSUGGESTED OPTION

to TRUE and rebuild/export to restore vanilla red artwork. No gameplay evaluation
or controller assignments are changed by this option.

SAVE PERSISTENCE
Moves/swaps update the current game plot table. Save normally after reordering;
no forced autosave or direct save-file edit is performed by EPW. Loading an older
save restores that save layout, not the most recent unsaved session layout.
Each save/character retains its own arrangement on both pages. New saves without
EPW data start with native order. Matching uses BaseName, falling back to PowerName.
Existing powers retain positions if native source order changes; new powers fill
the first hole. Removed powers leave holes. Opening still resets to page 0; hover,
selected move, page fade and help positions are transient and are not saved.
Visual preferences are build defaults, not a new runtime configuration menu.
LB/RB/Y assignments continue to use the game own save logic.
Plot integers 7400-7416 are EPW project allocations: marker plus sixteen identity
keys. Native LE2 integer arrays grow to at least 7417 entries (about 29 KiB total).
An occupied foreign block is not overwritten; mod compatibility is not guaranteed.
The data is inert after uninstall; removal does not require editing existing saves.
Copy the test save before checking persistence.
